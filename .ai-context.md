# AI Context - GO2 Hardware Bridge Sub-repository

## Feladatkör
Ez az alrepó a Unitree Go2 robot fizikai hardver illesztőit és szenzor-bridge moduljait tartalmazza:
- `webrtc_bridge/`: Natív Unitree WebRTC SDK csatlakozó (videó feed, telemetria, DDS átjáró).
- `hesai_bridge/`: Hesai LiDAR driver és pontfelhő feldolgozó.
- `realsense_bridge/`: Intel RealSense mélységi kamera bridge.
- `mc_sensor_hub/`: Nyers szenzoradat aggregátor.
- `rtl8821cu_driver/`: Wi-Fi illesztőprogramok és hálózati szkriptek.

## ROS 2 Topicok & Interfészek
- Közzétett kamerakép: `/webrtc/camera/image_raw` (`sensor_msgs/msg/Image`)
- Közzétett LiDAR pontfelhő: `/utlidar/cloud` (`sensor_msgs/msg/PointCloud2`)
- Robot telemetria: `/go2/highstate` (`unitree_go/msg/SportModeState`)

## Önálló Tesztelés (Mock)

```bash
python mock_hardware.py
```

## OmniVision 360 bridges (feature/omnivision-360)
- `thermal_bridge/` (FastAPI `:9120`, env `THERMAL_PORT`): 2× front UVC thermal cam (`th_front_narrow`, `th_front_wide`; InfiRay P2 Pro / TC001 class, pluggable decoders). `GET /cams`, `/cams/{id}/frame.npy|frame.png|stats`, `/health`. `--mock`.
- `maixsense_bridge/` (FastAPI `:9121`, env `MAIXSENSE_PORT`): rear MaixSense A010 ToF over USB serial (`tof_rear`). `GET /frame.npy` (100×100 m), `/frame.png`, `/points.npy`, `/health`. `--mock`.
- Tests: `python3 -m pytest thermal_bridge maixsense_bridge -q`
